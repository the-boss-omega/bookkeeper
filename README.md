# bookkeeper

A minimal web app for keeping track of daily routines.

- Add routines and check them off each day
- See your current streak and the last 7 days at a glance
- Data is stored locally in your browser (`localStorage`) — no account, no server

## Run

It's plain HTML/CSS/JS with no build step. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```
